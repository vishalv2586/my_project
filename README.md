# Getting Started

## Prerequisites

Install the following software before running the projects:

### Java Development Kit

```bash
java -version
javac -version
```

### MySQL

```bash
mysql --version
```

### Apache Maven

```bash
mvn -version
```

### Apache Tomcat

Tomcat is included in the repository for servlet-based projects.

---

# Running Java Programs

Compile:

```bash
javac FileName.java
```

Run:

```bash
java FileName
```
